# 3D 팀 오피스 대시보드 — 기획 (확정 2026-10-06)

## 한 줄 컨셉
팀의 작업 현황이 **3D 사무실 풍경**으로 보이고, 그 안에서 작업을 끌어다 사람 책상에 놓는 식으로
**실제 관리**를 하는 대시보드. 숫자만 뜨는 대시보드가 아니라, 만지는 재미와 보는 재미가 있는 관리 도구.

- 시점: 팀장/매니저가 한 팀(6~8명, 최대 10명)을 관리
- 스타일: 밝은 로우폴리 3D, 카메라 회전·줌
- 언어: 한국어 UI

## 화면 구성
- **가운데** 3D 오피스 — 팀원 아바타, 책상, 책상 위 작업 더미, 백로그 선반, 회의실, 휴게 공간
- **오른쪽** 관리 패널 — 칸반/목록 보기, 필터, 선택 대상 상세(작업/팀원)
- **위** 핵심 지표 — 진행 중, 지연, 이번 주 완료, 업무 편중도, 데모 모드 토글
- **아래** 활동 피드
- 3D ↔ 패널 선택·호버 연동, 필터 결과가 3D에도 반영(안 맞는 건 흐리게)

## 시각화 매핑
| 데이터 | 3D 표현 |
|---|---|
| 담당 작업량 | 책상 위 상자 더미 높이 (과부하면 흔들림) |
| 우선순위·마감 | 상자 색, 지연은 빨간 빛/연기 |
| 팀원 상태 | 작업 중=타이핑, 회의=회의실로 이동, 휴식=휴게 공간, 자리 비움=빈 의자 |
| 미배정 작업 | 입구 쪽 백로그 선반 |
| 완료 | 상자가 완료 선반으로 날아가는 연출 |
| 프로젝트 | 상자 라벨 색 |

## 1차 범위 (MVP)
1. 3D 오피스: 아바타·책상·작업 더미·백로그 선반, 클릭 선택, **드래그로 배정**
2. 작업 CRUD: 제목, 설명, 상태(할 일/진행 중/검토/완료), 우선순위, 마감일, 예상 포인트, 담당자, 프로젝트
3. 칸반/목록 + 필터(텍스트, 프로젝트, 담당자, 상태, 우선순위, 지연만)
4. **팀원 CRUD**: 이름, 역할, 색, 주간 여유량. 새 팀원은 빈 책상으로 걸어가 앉음. 삭제 시 남은 작업 처리 선택(백로그로 / 다른 사람에게)
5. 핵심 지표, 활동 피드, 오버레이(업무량 / 마감 위험 / 프로젝트)
6. 데이터: `DataSource` 인터페이스 뒤에 `MockDataSource`(시드 + localStorage) — 나중에 API/GitHub로 교체
7. 데모 모드: 가상 팀원들이 작업을 진행하고, 새 작업이 들어오고, 회의·휴식을 오감

## 결정 사항 (2026-10-06, 1차 리뷰 후)
- **스타일: 미니멀 & 깔끔.** 공간은 흰색/연회색, 색은 데이터에만. 소품 최소화, 이름표는 호버/선택 시에만.
- **아바타: 큐브 봇(A안).** 사람 형상 대신 둥근 큐브 몸통 + 앞면 화면 얼굴(눈 두 점), 팀원 색 하나.
- **심즈식 상태 표시 (채택 제안 3):** 아바타 머리 위에 천천히 도는 다이아몬드. 초록=여유, 주황=바쁨/마감 임박,
  빨강=지연/과부하. 아바타 클릭 시 심즈 상태창 같은 게이지 카드(업무량, 마감 압박, 집중도).
- **추천 액션 카드 (채택 제안 1):** "이도윤 님 업무량 140% → '쿠폰 검증' 작업을 정유진 님에게 [넘기기]".
  한 번 클릭으로 실행, 3D에서 상자가 날아감. 닫으면 다시 안 보임.
- 판정 로직은 `src/data/insights.ts` (memberSignal / memberVitals / suggestActions)에 공유.

## 로드맵 (2026-10-06 합의): C → A → D
- **C. 로컬 백엔드 연결** — 화면 코드 수정 없이 `ApiDataSource`로 교체되는지 증명. 계약: `docs/API.md`.
  - 스택: Hono + Node 내장 SQLite(`node:sqlite`), 실시간 변경은 SSE.
  - 데모 모드: API만 쓰는 **봇 클라이언트**로 분리(서버 프로세스가 호스팅, 모든 탭이 같은 사무실).
  - 서버 연결 실패: "서버에 연결할 수 없어요" 배너 + 자동 재연결.
  - `?source=api`로 전환, 기본은 지금의 가짜 데이터.
  - 같은 계약 테스트를 Mock/API 양쪽에 돌려 교체 가능성 검증.
  - 범위 밖: 로그인/권한, 배포.
- **A. 관리 기능 심화** (2026-10-07 합의: A1·A2 동시 진행)
  - **A1 회의실 (즉석 회의만)**: 작업 상자를 회의실 테이블에 끌어다 놓으면 안건(`onAgenda`). "회의 시작"에서
    이름·참석자 선택 → 참석자 봇이 회의실로 이동, 안건 상자가 테이블 위에. "회의 종료"에서 안건별 결정
    (배정/상태/백로그/보류) + 메모 → 한 번에 적용, 상자들이 각자 자리로 날아감. 최근 회의록 열람.
    한 번에 회의 하나. 예약 회의는 범위 밖.
  - **A2 주간 계획**: 패널 "주간" 탭 — 팀원 × 요일(월–금) 그리드, 칸마다 마감 작업과 포인트, 팀원별 주간
    여유량 대비 합계. 작업 카드를 다른 칸으로 끌면 마감일(다른 팀원 행이면 담당자도) 변경. 지난주/다음주 이동.
    기존 데이터(마감일)만 사용 — 계약 변경 없음.
- **D. 품질** — 반응형, 번들 크기, 테스트 보강. 리뷰에서 넘어온 항목:
  - 공통 규칙 모듈 `src/data/rules/` (검증, 활동 메시지, 작업 조작 헬퍼, 데모 작업 풀) 추출 →
    mock과 server가 함께 사용, 복사본 제거. architect 소유 계약 파일로 지정.
  - `tests/`, `scripts/`, `server/`를 `tsc -b` 참조에 포함(tsconfig.tools.json + composite).
- (B 게임 감각은 A 진행 중 필요한 연출만 함께.)
